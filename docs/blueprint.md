# **App Name**: GeoMapper

## Core Features:

- Data Layer Display: Display data layers on a 2.5D interactive map.
- Data Layer Toggling: Allow users to toggle different data layers on and off.
- Interactive Map Navigation: Enable panning and zooming on the map for detailed exploration.
- Data Details on Click: On clicking, reveal data details of the clicked map element.
- Data Filtering: Allow filtering of the data displayed on the map based on selected criteria.
- AI Data Layer Suggestions: Offer AI-driven suggestions tool, for relevant data layers based on the currently viewed map area.

## Style Guidelines:

- Background color: Dark charcoal gray (#333333) for a modern, data-focused feel.
- Primary color: Vibrant teal (#008080) to highlight interactive elements and key data points.
- Accent color: Electric blue (#7DF9FF) for secondary interactive elements.
- Font pairing: 'Space Grotesk' (sans-serif) for headers and 'Inter' (sans-serif) for body text. 
- Use minimalist icons with teal and blue accents to represent data layers and filtering options.
- Design a clean, intuitive layout with map taking up the majority of the screen and data controls easily accessible.
- Implement smooth transitions and subtle animations for data layer toggling and map navigation to enhance user experience.
